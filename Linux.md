**Structure of Linux:**

**...................**

**Application:** Software used by users to perform tasks, such as Chrome, Python, and Git.

**Shell:** A command interpreter that accepts user commands and communicates with the kernel.

**Kernel:** Kernel is a core component of a Linux where it will process the data and generate output by taking help of hardware.

**Hardware:** The physical components of the computer, such as the CPU, RAM, keyboard, mouse, and hard disk.
